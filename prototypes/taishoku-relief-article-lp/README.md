# 退職リリーフ 記事型LP 試作

既存のLP試作とは別に作成した、長文ブログ・調査記録の読み心地を使う第2試作です。実在しない受給体験は作らず、「月約20万円の可能性 → 自分の条件 → 退職前にすること → 退職リリーフを選ぶ理由 → 不安と料金の確認」の順で読ませます。

## ローカル確認

このフォルダを静的サーバーで開くと `index.html` を確認できます。現在の確認用URLは `http://127.0.0.1:4174/` です。

## この試作の前提

- 体験談の導入・段階的な納得感は使うが、実在しない利用者の成果・口コミ・数値は載せない
- 生成した挿絵3点はこの試作専用のオリジナル素材
- CTAは退職リリーフ公式LINE（`https://lin.ee/GjxwUdS`）へ接続済み
- CTAごとに `data-cta` を分け、記事内のクリック位置を計測しやすくしている
- 制度を知らない人、不安を先に確認したい人、比較中の人、退職日が近い人の4導線をFV直下に設置
- 料金は公式の特定商取引法表記で確認した前払い価格を表示し、支援範囲・本人が行うこと・契約前の確認条件を同じ場所に配置
