## 4. ASPへ送るCR資料

`ASP_CR_CONFIRMATION_REQUEST.md` は、**RSAの見出し・説明文だけ**を載せたASP送付用資料である。キーワード、入札、LP、URL、サイトリンク、コールアウト、媒体設定は含めない。

数値訴求案の `条件により最大365万円` は、通常RSAから隔離して同資料の末尾にだけ置いている。承認前は配信しない。
