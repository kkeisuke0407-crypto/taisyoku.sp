# 退職リリーフ｜Google検索広告文 CR確認依頼

確認対象は下記の**広告文（RSA見出し・説明文）だけ**です。キーワード、入札、LP、URL、アセット、媒体設定は含めません。

確認してほしい点: 金額・期間・受給可否の誤認、受給額等を増やせる示唆、診断・受診の誘導、行政判断の断定がないか。
