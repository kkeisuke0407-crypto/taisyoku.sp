# 退職リリーフ：データのみのPPC案件評価

評価日: 2026-07-21  
評価範囲: 提示された案件数値のみ。法令・LP表記・消費者保護・外部評判は評価対象外。  
判定: **A：小額テスト候補**（ハウスガードの主力検証とは別枠。いきなり主力化しない）

## 結論

この案件は、**PPCでLINE追加を2,000円以下で取れるなら成立する**。  
提示値のCVR 22%がPPC流入でも再現するなら、期待売上は1クリック当たり880円であり、CPC 300〜400円の帯なら十分に利益を残せる。

一方で、成果単価は4,000円であり、初月の全体上限は300件。高CPCに耐えて大きく伸ばす案件ではない。`低〜中CPC × 高CVR × 直LP` が再現できるかを7日間で判定する案件である。

## 入力値

| 項目 | 値 |
|---|---:|
| 成果報酬 | 4,000円 / LINE追加 |
| 承認 | 基本全承認（重複・不正・悪質いたずらを除く） |
| 平均CVR | 22% |
| 初月上限 | 300件（全体） |
| 獲得実績 | 2,000件 / 月 |
| 好調媒体 | SEO、PPC |
| PPC導線 | 直LP可、タグ設置可、Metaピクセル共有可、全商流タグ設置可 |
| 承認/確認 | 提携手動、記事・CR確認は各3営業日以内目安 |

## ユニットエコノミクス

期待売上 / クリック = `4,000円 × CVR 22% = 880円`

| 実CPC | CVR 22%時のLINE追加CPA | 1件あたり粗利（報酬 - 広告費） | 判断 |
|---:|---:|---:|---|
| 300円 | 1,364円 | 2,636円 | S |
| 400円 | 1,818円 | 2,182円 | S |
| 500円 | 2,273円 | 1,727円 | A |
| 600円 | 2,727円 | 1,273円 | B |
| 800円 | 3,636円 | 364円 | C |

運用上の採用基準は **LINE追加CPA 2,000円以下**。  
そのため、CPC 400円なら必要CVRは20%、CPC 300円なら必要CVRは15%となる。

## データからの強み

1. **成果地点が軽い。** LINE追加で発生し、基本全承認なので、広告→成果までの判定が早い。
2. **CVR 22%が高い。** PPCでも再現するなら、4,000円案件として十分に戦える。
3. **PPC向けの計測余地がある。** 直LP、タグ、Metaピクセル、全商流タグが可。広告別の改善を回せる。
4. **増枠余地が明示されている。** 初月300件は小さいが、実績2,000件/月と増額可の記載があり、初期テストを通す理由がある。

## データからの弱み

1. **報酬4,000円はCPC耐性が低い。** 22%CVRでもCPC 600円を超えると余白が薄い。
2. **初月300件は全体上限。** 自分の配分は不明なので、上限到達・媒体配分で急停止する可能性がある。
3. **CVR 22%の定義が不明。** ここだけは開始前に確認する。分母が「PPCのLP到達」なら強い。SEO・PPC合算、LINE到達後、特定LPのみ等なら期待CPAは変わる。
4. **手動提携・記事/CR確認がある。** テスト開始までのリードタイムは数日必要。

## 実施判断

### 先に確認する数値（1問だけ）

`平均CVR 22%は、PPC流入のLPセッション→LINE追加完了のCVRですか？ 直近30日または90日のPPC単独値もください。`

この答えが「PPCでも20%前後」なら、テスト実施。PPC単独で15%未満なら、4,000円案件として優先度を下げる。

### 初期テスト

- 期間: 7日
- 予算: 日額3,000円、上限21,000円
- 配信: 1キャンペーン、2広告グループまで。完全一致を中心に開始
- 入札: 初期CPC上限400円。CPCが500円を超える語は、CVRが22%を維持しても追加しない
- 計測: 広告クリック、LP到達、LINE追加完了、CPA、検索語句

### 継続/停止基準

| 状態 | 判断 |
|---|---|
| 20クリック以上、LINE追加CPA 2,000円以下 | 継続。勝ちKWを完全一致で隔離し、日額を5,000円へ。 |
| 20クリック以上、LINE追加CPA 2,001〜2,500円 | CPCを下げ、広告/検索語句を精査。拡張しない。 |
| 20クリック以上、LINE追加ゼロまたはCPA 2,500円超 | 停止。 |
| 初月上限が残り少ない | 配信開始しない。翌月の配分を確認。 |

ハウスガードを未黒字のまま、退職リリーフを本格拡張しない。ただし、この案件は成果地点が軽く、7日で数値判定ができるため、主力の制作を止めない範囲の小額テストは合理的。
