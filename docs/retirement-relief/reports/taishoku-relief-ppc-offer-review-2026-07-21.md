# 退職リリーフ：PPCアフィリエイト案件評価

調査日: 2026-07-21  
広告主: 労働組合 新宿ユニオン  
結論: **C/D・現時点では出稿見送り**

## 結論

LINE追加4,000円、基本全承認、平均CVR 22%、PPC実績という表面条件だけなら、小額検証の候補に見える。しかし、PPCアフィリエイトとしては推奨しない。

理由は、退職リリーフの公式サイトにおいて、失業手当サポートを298,000円（税込、前払い）または398,000円（税込、後払い）で販売し、より高額なプランもあること、返金保証の訴求と特商法表記の返金不可条項が並存すること、そして失業保険の給付額増額をうたう高額サポートへ消費者注意喚起が出ていることにある。

ここで問題にしているのは、新宿ユニオンが違法であるとの断定ではない。広告表現、受給要件、顧客への費用説明が少しでもずれたときに、広告主・媒体・アフィリエイターが背負う規制・返金・ブランド毀損リスクが高いという事業判断である。

## 1. 勝ち筋の有無

### プラス材料

- 成果地点はLINE追加で、案件情報上は基本全承認。最終受任まで待たず成果が発生するため、計測は速い。
- 平均CVR 22%が「広告流入からLINE追加」の値で正確なら、クリック1件あたりの期待売上は `4,000円 × 22% = 880円`。
- 直LP可、タグ設置可、PPC実績あり、記事/CR確認も3営業日目安と、運用インフラは整っている。

### しかし勝ち筋が弱い理由

- 4,000円は退職・失業保険系の検索広告で高い単価ではない。損益分岐CPCは880円だが、広告費以外の利益を残すなら、許容CPCは目安で352〜440円（粗利50〜60%確保時）まで下がる。
- 「平均CVR 22%」の分母が不明。直LP全セッションなのか、承認済み流入だけなのか、SEO/PPC合算なのか、特定クリエイティブだけなのかで価値が大きく変わる。
- 月間2,000件の獲得実績に対して初月全体上限300件。上限が埋まれば停止するため、受任率を満たす良質リードを出せない限り、継続性が不透明。

## 2. 参入リスク

### A. 公式LPの契約・返金表記

公式LPは「万が一受給できなかった場合は、全額返金保証」と訴求する。一方、特定商取引法に基づく表記には、失業手当サポートが前払い298,000円・後払い398,000円、契約時の保証金があり、原則としてキャンセル・返金不可と記載されている。

広告や比較LPで「返金保証」「受給できる可能性」「自己都合でも可」を押すと、ユーザーが想定するサービスと実際の有償契約条件のズレを増幅させる。記事・CRの事前確認が必須なのは、このリスクの裏返しでもある。

### B. 制度訴求のリスク

雇用保険の基本手当は、単に退職すれば受給できる制度ではない。被保険者期間、離職理由、求職意思・就労可能性等の要件で決まり、支給日数・日額も個別条件で変動する。

青森県消費生活センターは2026年2月、「失業保険の給付額を増やせる」とする高額サポートについて、断定的な給付額広告を信用しないこと、申請手続の代行は社会保険労務士又は弁護士が行うこと、不正受給には返還や刑事罰の可能性があることを注意喚起している。

### C. 運用・媒体リスク

- `LINE追加`という軽い成果地点は、興味本位・給付金だけを期待する低品質リードを量産しやすい。案件側が「受任率を見て増額」と明記しているため、質が悪ければ上限停止・単価変更のリスクがある。
- 電話番号アップロード不可のため、最終受任との照合を広告側で精密に行いにくい。LINE追加CPAが良くても、受任率が悪い場合に原因を戻せない。
- 直LP可でも、記事確認・CR確認が必須。独自の比較LPで法令リスクを吸収しづらく、出稿前の承認範囲を超える改善ができない。

## 3. 初期ターゲット（出稿する場合のみ）

この案件を解禁できる唯一の初期ターゲットは、`退職予定で、雇用保険の受給要件・手続き・受給開始時期を正確に確認したい人`。

「失業保険を増やす」「最大○万円」「診断書で増額」「会社都合に変える」等、受給額を増やす/離職理由を操作する期待を含む流入は、規制・不正受給・低受任のリスクが高く、対象にしない。

## 4. キーワード案（条件解除後のみ）

`[退職後 失業保険 手続き]`  
`[自己都合退職 失業保険 いつから]`  
`[退職前 失業保険 相談]`

これらでも情報収集意図が強く、直接LPへ送るだけではLINE追加後の質を担保しにくい。実施するなら完全一致のみ、短期間の品質テストに限る。

## 5. 初期除外キーワード

`増額 / 最大 / 200万 / 300万 / 受給額 増やす / 不正受給 / 会社都合にする / 診断書だけ / うつ病 診断書 / 嘘 / 偽造 / 裏技 / 失業保険 もらいながら 働く / ハローワーク 騙す / 無料`  
商標・競合名は、許諾がない限り除外。

## 6. LP・広告表現

今の案件条件では独自比較LPの運用を推奨しない。直LP可であっても、広告・記事の事前確認が必須であり、公開LPの高額契約・返金条件と整合する表現を個別承認なしに作れないからである。

使う可能性がある表現は、広告主の事前承認を得た以下に限る。

- `受給要件を確認したい方へ`
- `雇用保険の手続きに関する相談`
- `受給可否は個別の条件により異なります`

使わない表現:

- `失業保険を増やせる`
- `自己都合でも必ず受給`
- `最大○万円`
- `受給保証`
- `誰でも対象`
- `診断書で給付日数を増やす`

## 7. 計測設計

LINE追加だけで最適化しない。広告主に、媒体/キャンペーン/キーワード単位で以下の匿名集計を週次共有してもらえるか確認する。

`LINE追加 → 有効接触 → 面談/説明 → 契約 → 受任 → 返金・解約`

最低限、媒体別のLINE追加数、重複・いたずら率、初回有効接触率、受任率、上限消化状況を受け取れないなら、PPCの品質改善はできない。

## 8. 初期予算と撤退基準（条件解除後のみ）

- 開始は日額3,000円以下、完全一致のみ。
- 目標はLINE追加CPAではなく、媒体別の有効接触率・受任率が既存媒体を下回らないこと。
- LINE追加CPA 2,000円以下でも、有効接触率または受任率が開示されない/悪い場合は即停止。
- CPCが440円を上回る状態で、22%のCVR再現が確認できない場合は停止。
- 上限300件の残数が少ない、または記事・CR承認が失効した場合は出稿しない。

## 9. 7日目 / 14日目 / 30日目

| 時点 | 判断 | 実行 |
|---|---|---|
| 7日目 | 広告・記事の承認範囲とLINE追加CPAを確認 | 受給額増額・不正受給期待の検索語を除外。媒体別有効接触率が未開示なら停止。 |
| 14日目 | 受任率/重複率を既存媒体と比較 | 既存媒体を下回るなら入札・KWを削る。改善不能なら停止。 |
| 30日目 | 受任率と上限/増枠を判定 | 事前に合意した品質基準を満たし、増枠が書面で確定した場合のみ継続。それ以外は撤退。 |

## 出稿判断を覆すための必須確認

次を広告主/ASPから書面で受け取れない限り、PPC出稿しない。

1. サービス契約の正式な利用規約、返金条件、途中解約条件、総支払額
2. `全額返金保証` と `原則返金不可` の適用関係
3. 雇用保険・傷病手当の手続きで、誰が何を行うか（社労士・弁護士・労働組合の役割）
4. 利用者が満たすべき受給要件、対象外者、広告で使える確定表現と必須注釈
5. PPCだけの過去90日間の、LINE追加→有効接触→受任率→返金/解約率
6. 初月300件上限の残数、媒体別配分、受任率基準、増枠/停止の具体条件
7. LINE追加CVR 22%の分母・期間・媒体別内訳
