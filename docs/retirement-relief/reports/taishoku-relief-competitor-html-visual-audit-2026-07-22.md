## 2. 競合ごとの「取る／取らない」

### 失業保険サポート

- **観測:** 濃紺、人物の大きな切り抜き、黄色の丸CTA。ファーストビューの人物画像は約730×683px。説明会とLINEを同格で繰り返す。
- **取る:** 「いま次にすること」が分かる大きな図解と、行動を迷わせないCTAの配置。
- **取らない:** 紺・金・人物切り抜き・二大CTAの組み合わせ。金融系LPの既視感が強く、退職リリーフの診断導線とも競合する。

### 未来退職

- **観測:** ブランド色はティール `rgb(1,182,173)`。Noto Sans JPにDosisを補助的に組み合わせる。相談内容やお知らせを更新コンテンツとして見せ、ページ自体を情報拠点にしている。
- **取る:** 一回きりの広告LPにせず、Q&Aや相談の具体的な言葉をページの信頼材料にする考え方。
- **取らない:** サイドバー風の情報量と、ニュース一覧から始まる読み方。検索広告から来た人には、最初の判断が遅くなる。

### 退職給付金申請サポート（r-support.work）

- **観測:** 27セクション。背景画像＋人物写真のヒーロー、濃紺の100px見出し、緑からティールへ変化するCTA。数字や大きなキーワードをポスター的に重ねる構成。
- **取る:** 退職を抽象語で語らず、生活者の場面を写真で一瞬で伝えること。
- **取らない:** 極大見出し、緑のグラデーション、長いポスター連続。広告で見慣れた型になりやすく、検索語との距離もできる。

### 退職コンシェルジュ

- **観測:** 白地、Noto Sans JP／Lato／Oswald。横長の訴求バナーをファーストビューに重ね、LINEと説明会の画像ボタンを併置。セクションは11で、比較的サービス案内に寄っている。
- **取る:** 大きなサービス説明の前に、行動を選べる導線を置くこと。メニューや導線の運びは整っている。
- **取らない:** 画像内文字のバナー連打。修正・ABテストしにくく、スマホで文字が小さくなりやすい。

### YELL!!

- **観測:** 暖色のオレンジ `rgb(251,151,64)` が唯一の強いアクセント。デスクトップは約1265×553px、モバイルは約375×667pxの写真ヒーローを使う。LINE CTAはオレンジのピル型。
- **取る:** 色を一色に絞り、生活感のある写真を一枚だけ大きく使う潔さ。
- **取らない:** ブランド色をCTA・見出し・装飾に同時多発させること。退職リリーフでは既存のLINEグリーンとぶつかる。

### 退職リリーフ（基準）

- **観測:** `Noto Sans JP`本文、`Noto Serif JP`補助。写真の上に白い透過グラデーションを重ね、深い青緑の40px H1、LINEグリーンのピルCTA、右側に会話の疑似表現を置く。14セクション。
- **残す:** 「LINEで相談する」ことを視覚的に理解できる会話表現、落ち着いた青緑、無理のないCTA。
- **変える:** ヒーローの「不安 → 診断」という一方向性。検索語が `いつから` / `待機期間` の人には、現在地を選ぶ余地を最初に作る。

## 3. 6社を通して見えた共通の型

1. 長尺で、セクション数が多い。
2. ファーストビューで大きい数値・人物・CTAを同時に置く。
3. LINE、説明会、無料診断のうち二つ以上を同格に置く。
4. 色は紺・ティール・緑・オレンジのいずれかを強く使い、丸ボタンで締める。
5. 「悩み → 制度説明 → サービス → 声 → 流れ → FAQ」の同じリズムに収束している。

このまま要素を足すと、内容を変えても量産LPに見える。退職リリーフは、**最初に現在地を整理すること自体を体験にする**ことで、構造を変える。

## 4. 退職リリーフの推奨ビジュアル方針

### 主題: 退職前後の「手続きノート」

派手な給付金広告ではなく、机の上で退職後の段取りを一つずつ確認する感覚。読者が検索している `いつから` / `待機期間` / `手続き` を、時間軸として見せる。

- **トーン:** 静かな実用編集。冷たい役所感でも、煽る金融広告でもない。
- **最初の画面:** 大きな写真＋見出しではなく、見出しの隣に「退職前 / 退職直後 / 離職票待ち」の細い縦の時間軸を置く。カードを三枚並べない。
- **写真:** 手元、封筒、カレンダー、ノートなど実際の“確認する場面”を一枚だけ。人物の切り抜きや笑顔のオフィス素材は使わない。
- **情報の密度:** 1画面で1つだけ判断できる量にする。長い説明はアコーディオンに隠すのではなく、下の「検索でよくある疑問」に回す。

### 色・文字

| 役割 | 方針 |
|---|---|
| 背景 | 黄みのある薄い紙色。純白を連続させない |
| 文字 | 黒ではなく、少し緑を含む濃い墨色 |
| 主アクセント | 退職リリーフの深い青緑。罫線、見出し下線、時間軸に限定 |
| 行動色 | LINEグリーン。CTAだけに使い、他の装飾へ広げない |
| 補助色 | ごく淡い土色。日付・注釈・ノートの区切りにだけ使う |
| 表示書体 | 明朝系を見出しだけに限定し、本文は読みやすいゴシック。見出しを斜体にしない |

## 5. 既存LPと違うページのリズム

```
現在地を選ぶヒーロー
  ↓
「今日、先に見ること」1枚の短いノート
  ↓
検索語別の3つの疑問（いつから / 待機期間 / 手続き）
  ↓
LINE診断で整理できること
  ↓
サポート内容と流れ
  ↓
承認済みの声・FAQ・最後のCTA
```

一般的な「悩みカード3枚 → サービス特徴3枚」から始めない。ヒーローから直後のセクションまでを、一本の時間軸でつなげる。

## 6. 実装時の非テンプレ規則

- 同じ角丸カードを連続で使わない。繰り返しが必要なのは検索語の3項目とFAQだけ。
- アイコンセットだけで意味を作らない。時間軸、罫線、短い手書き風の注記など、内容と結びつく要素を使う。
- ヒーロー内にカードを置かない。文章・CTA・時間軸を同じ紙面として扱う。
- グラデーション背景、浮遊する丸、過剰な影、丸い統計バッジを使わない。
- 証言・実績・監修者は広告主の承認済み素材のみ。プレースホルダーの顔写真・架空コメント・架空数値は置かない。
- スマホでは縦の時間軸を残し、固定CTAは1行で収める。PC用の横ナビをそのまま縮めない。

## 7. LP実装に入る前の固定決定

**想定読者:** 自己都合で退職した／する予定で、手続き開始時期や待機期間を検索している人。  
**一つの行動:** LINEで現在地を確認する。  
**デザインの極性:** 静かな実用編集（editorial utility）。  
**捨てる型:** 紺×金、人物切り抜き、数値バッジ、特徴3枚、説明会とLINEの二大CTA。  
**使う固有モチーフ:** 退職前後の時間軸、手続きノート、必要最小限の罫線。
