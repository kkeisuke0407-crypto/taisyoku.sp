- [PPC_AFFILIATE_LISTING_MATERIALS_2026-07-31.md](PPC_AFFILIATE_LISTING_MATERIALS_2026-07-31.md): PPCで競合として見るべきアフィリエイター／送客記事の検索面・LP・HTML材料（広告主LPとは分離）
- [PPC_KEYWORD_AND_AD_COPY_MATERIALS_2026-07-31.md](PPC_KEYWORD_AND_AD_COPY_MATERIALS_2026-07-31.md): 検索語、Googleサジェスト、広告枠観測、アフィリエイト送客記事の金額見出し・CTA、ローカル試作との差分
- [RETIREMENT_SCENARIO_AND_KWP_SEEDS_2026-07-31.md](RETIREMENT_SCENARIO_AND_KWP_SEEDS_2026-07-31.md): 解雇以外の退職事情を含めた検索材料と、KWPで数値を取り直すためのシード。KWP数値は取得後に追記する。
- [MATERIALS.md](MATERIALS.md): サービス、制度、検索画面、広告主LP、FAQ、CTA、HTMLの観測記録
- `official-page-inventory.csv`: 公式サイト内のページ別の見出し・導線
- `competitor-lp-inventory.csv`: 競合各社の公開LPで観測できた構成要素
- `serp-materials.csv`: 実際のGoogle検索画面に現れた結果・関連検索語・広告表示の観測
- `affiliate-serp-query-log-2026-07-31.csv`: 46検索語に対するアフィリエイト型・比較型ページの出現ログ
- `affiliate-lp-html-audit-2026-07-31.csv`: 送客型LPの外部リンク、ASPリンク、CTA、見出し、除外区分
- `ppc-keyword-materials-2026-07-31.csv`: 50語のキーワード素材。出所、検索面、過去の数値スナップショット、試作内の言葉を1行ずつ分離
- `ppc-ad-copy-observations-2026-07-31.csv`: 実広告の未観測と、送客記事・ローカル試作に表示されたtitle、見出し、CTAの観測を分離した表
- `kwp-seeds-2026-07-31.csv`: 意図別のKWP投入用シード46語。KWP数値をまだ入れていない状態。
- `html-audit.csv`: 静的HTMLのサイズ、title、見出し、form、LINE遷移先
- `evidence.csv`: 制度・注意喚起・公式ページの根拠URL一覧

## 読み方の前提

- 「観測」は記載日の公開ページ・検索画面から採ったもの。検索順位、広告、LPの内容は地域・端末・時刻で変動する。
- 競合の数字、体験談、満足度、受給期間・受給額などは、各社が公開LPで掲げる表現の記録であって、真偽・再現性・適用範囲を保証しない。
- 公的制度は個々の離職理由、加入期間、就労可能性、健康保険の加入状況等で変わる。本文では一般論と個別案件の表示を混ぜない。
- ユーザーから共有されたASP条件は、案件票上の情報として収録した。公開ページとの照合が済んだ契約条件ではない。
