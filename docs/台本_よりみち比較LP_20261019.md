### 2-3 ③ ひとりだと難しい3つの理由　`detail-4` yk-order ＋ `detail-5` yk-numh　section_id=`intro_why`
書き方：見出しは結論だけ（短く・数字入り）→ 太字の1行でドキッとさせる → 説明は短い文を2〜3つ → 数字の例。

目次の3行（yk-numh の見出しと同じ文言）：
- 理由1　同じ人でも、もらえる日数が3倍以上ちがう
- 理由2　辞める日が1日ちがうだけで、約17万円の差
- 理由3　求人サイトを毎日見ても「活動0回」

**理由1　同じ人でも、もらえる日数が3倍以上ちがう**
<b>失業保険は「もらえる日数」が人によって決まっていて、90日の人もいれば300日以上の人もいます。</b>
どの日数になるかは、辞めた理由などで分けられた「区分」で決まります。
ハローワークは、会社が書いた辞めた理由と、あなたの申し出の両方を見て判断します。
<mark>何も知らずに手続きすると、あなたの事情が伝わらないまま進んでしまう</mark>ことがあります。

例（yk-listbox で囲む。数字は緑）：1日あたり5,632円の人なら
- 90日だと　→ 約51万円
- 300日だと → 約169万円
※よりみち給付金サポート公式サイト掲載の事例（34歳・製造業）の1日あたりの金額で計算。日数は区分ごとに法律で決まっています（90〜360日）。

- 根拠：S11（区分別の日数）、S12・S13（離職理由は会社と本人の主張を資料で確認して判定）、S01 case1（5,632円×90日＝506,880円／×300日＝1,689,600円）
- 注意：「サポートで増える」とは書かない。差は「区分のちがい」として説明する

**理由2　辞める日が1日ちがうだけで、約17万円の差**
<b>雇用保険に入っていた期間が「9年11か月」で辞めると90日。「10年」まで待てば120日。</b>
たった1か月ちがいで、もらえる日数が30日も変わります。1日あたり5,632円なら、約17万円です。
ほかにも、自己都合で辞めると最初の1か月はもらえませんが、<mark>辞める前の1年以内に対象の講座を受けておけば、この1か月の待ちがなくなります</mark>。
<red>どちらも、辞めた後では手遅れです。</red>だから、辞める日を決める前に聞いておくことが大事です。

例（yk-listbox）：
- 9年11か月で辞める → 90日
- 10年で辞める → 120日（＋30日分）
※自己都合の場合。対象の講座と手続きはハローワークで確認できます。

- 根拠：S14（一般の離職者 10年未満90日／10年以上120日／20年以上150日）、S15（給付制限は原則1か月・離職日前1年以内の教育訓練で解除・申出が必要）、S01（日額の例）
- 「1日ちがい」は期間の区切りが日単位で数えられるため。見出しは「1日」、本文の例は分かりやすく「1か月」にする

**理由3　求人サイトを毎日見ても「活動0回」**
<b>失業保険は、もらい始めた後も4週間に1回ハローワークに行き、「仕事を探しました」と報告します。</b>
報告には、原則2回以上の求職活動が必要です。
ところが、<red>求人サイトを見ていただけでは、1回にも数えられません</red>。数えられるのは、求人への応募や職業相談などです。
こういう細かいルールを、最初にまとめて教えてもらえるかどうかで、つまずき方が変わります。

- 根拠：S13（原則4週間に1度の失業認定・原則2回以上の求職活動・「単なる…インターネットなどでの求人情報の閲覧…だけでは含まれません」）、S01（専属コンシェルジュが受給までの流れを説明）

よくある質問（回答はS01・S02・S10。公式にないことは書かない）
1. **怪しいサービスではない？**　運営は株式会社よりみち（東京都中央区日本橋室町）で、弁護士法人プロテクトスタンスが監修しています。失業保険を支給するのはハローワークで、審査を受けて決まります。公式は「不正な受給を促すものではない」と明記しています。
2. **料金はいくら？**　LINEの無料診断までは無料です。サポートの料金は公式サイトに載っておらず、個別相談で示されます。金額と支払い方を聞いてから決めましょう。
3. **自己都合で辞めても使える？**　使えます。公式は、自己都合でも会社都合でも手続きとスケジュールは同じと案内しています。
4. **いつ相談すればいい？**　公式のおすすめは、退職予定日の1か月前です。有休消化中でも、退職日までに準備ができれば申請できます。
5. **会社に知られない？**　公式は、失業保険の受給は会社にお金の負担がかからず、会社に知られることもないと案内しています。
6. **申請は自分でするの？**　失業保険の手続きはハローワークで本人が行います。よりみちは書類の準備と申請をサポートします。
